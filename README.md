# Portfólio de Sites — Negócios Locais

Coleção de landing pages e catálogos online desenvolvidos como portfólio para clientes de pequenos negócios (barbearias, restaurantes, salões, etc). Todos os sites são em português, feitos em HTML/CSS/JS puro (sem build step), para ficarem fáceis de customizar e publicar em qualquer host estático (Netlify, Vercel, GitHub Pages, etc).

## Projetos

| Projeto | Tipo | Pasta |
|---|---|---|
| Barbearia Império | Landing page | [`barbearia-imperio/`](barbearia-imperio/) |
| Point do Açaí | Landing page + cardápio | [`point-do-acai/`](point-do-acai/) |

## Padrão dos projetos

Cada projeto é autocontido em sua própria pasta:

```
nome-do-projeto/
  index.html
  css/style.css
  js/script.js
  README.md   (pontos de customização específicos)
```

Para visualizar, basta abrir o `index.html` no navegador ou servir a pasta com qualquer servidor estático.
