# Barbearia Império

Landing page para barbearia — tema clássico (preto e dourado), 100% HTML/CSS/JS puro, sem dependências além do Google Fonts.

## Seções

Início (hero) · Serviços · Sobre · Galeria · Depoimentos · Localização · CTA final · Rodapé. Botão flutuante de WhatsApp.

## Antes de publicar para um cliente real

- [ ] Trocar o número de WhatsApp `5511999999999` (aparece no header, hero, localização, CTA final, rodapé e botão flutuante)
- [ ] Atualizar endereço e horário de funcionamento (seção `#localizacao` e rodapé em `index.html`)
- [ ] Atualizar as coordenadas do `<iframe>` do Google Maps na seção `#localizacao`
- [ ] Trocar os links de Instagram/Facebook no rodapé e adicionar o link real do WhatsApp
- [ ] Substituir os blocos da seção `#galeria` por fotos reais dos cortes/ambiente
- [ ] Ajustar nome do negócio, textos, preços dos serviços e depoimentos
- [ ] Atualizar o crédito de desenvolvimento no rodapé (`[Seu Nome / Sua Marca]`)

## Visualizar

Abra `index.html` diretamente no navegador, ou sirva a pasta com um servidor estático, por exemplo:

```
npx serve .
```
